Ticker Settings

In OBS's Interact window, click anywhere on the page to open this panel. Changes apply live and save automatically. Click Done below when you're finished - that's the only thing that closes it, so nothing you type can accidentally dismiss it. Set the OBS Browser Source to match your canvas resolution, then add a Chroma Key filter on it (Custom Color, matched to the "Greenscreen" swatch below) so only the ticker bar shows over your scene.
